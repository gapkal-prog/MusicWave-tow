## Multisite Smoke (FIX-41)

**Steps:**

```bash
npx @wordpress/env start --multisite
npx @wordpress/env run cli wp site list
npx @wordpress/env run cli wp plugin activate music-wave-core music-wave-vip --network
npx @wordpress/env run cli wp theme activate musicwave --url=http://localhost:8888
# Create subsite
npx @wordpress/env run cli wp site create --slug=test2
# Check tables per site
npx @wordpress/env run cli wp db query "SHOW TABLES LIKE '%mw_%'" --url=http://localhost:8888
npx @wordpress/env run cli wp db query "SHOW TABLES LIKE '%mw_%'" --url=http://localhost:8888/test2
# Uninstall on subsite (delete_data_on_uninstall=enabled)
npx @wordpress/env run cli wp option update music_wave_settings --format=json '{"delete_data_on_uninstall":"enabled"}' --url=http://localhost:8888/test2
npx @wordpress/env run cli wp plugin uninstall music-wave-core --deactivate --url=http://localhost:8888/test2
# Verify posts intact, tables dropped
```

**Expected:**

- No fatal on network activate
- Tables created per site with prefix (`wp_`, `wp_2_`, etc)
- `music_wave_settings` per site
- Uninstall OFF keeps data, ON drops `mw_*` tables, keeps `mw_release` and `mw_request` posts
- Cron cleared per site
- No `music_wave_` options left after ON delete

**Report:** see `docs/audits/multisite-smoke.md` (generated by run-audits.sh, manual until CI has multisite job).
